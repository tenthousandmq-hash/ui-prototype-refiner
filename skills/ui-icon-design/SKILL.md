# UI 图标工程装配与替换 (UI Icon Design & Assembly)

本 Skill 承载 UI 工程化流水线中图标领域的**装配执行（Implementer）**职责。
本 Skill 专职负责将混乱、残缺或原型阶段的控件符号，替换为工业级标准的矢量资产。

---

## 一、准入前提与作用域界定（Scope & Authorization Gate）

* **前置锁**：只有在收到明确的“重构/更换图标”授权指令，或进入全流程新页面设计任务时才激活；
* **承重墙保护**：若需求说明中明确标记“不要动图标”或未获得图标修改权，**严禁加载本 Skill，保持现有图标作为承重墙完全不动**；
* **内容媒体豁免原则（Content Media Exemption）**：
  * 本 Skill 的治理作用域**仅限交互控件内部的功能符号**（如侧栏导航、按钮伴随图标、表单前缀、树节点展开折叠符）；
  * **严禁触碰任何业务内容型媒体**：页面中的用户头像（Avatar）、文章封面配图、商品缩略图（Thumbnail）、品牌或组织 Logo 等 `<img>` 标签，**100% 属于业务数据承重墙，绝不干预、绝不替换为 SVG**。

---

## 二、宽框架四大物理底线（The 4 Broad Guardrails）

流水线不给大模型设置碎屑死板的微观规则，只死卡以下四条物理底线：

### 1. 尺寸 4px 乘数阶梯（16px 最低物理底线）
* 图标物理尺寸严格收敛至 4px 倍数阶梯：
  * **`16×16px` (4×4)**：交互图标的**绝对最低底线**（侧栏导航、树节点、紧凑表格、表单控件）；
  * **`20×20px` (4×5)**：标准主动作栏、独立按钮伴随图标；
  * **`24×24px` (4×6)**：大视窗卡片引导、顶部主入口；
  * **`32×32px` (4×8)**：空状态与模态框头部。
* **物理禁令**：严禁使用 14px、15px、17px 等奇数或非标碎屑尺寸。奇数尺寸在 24×24 视口下必然引发 `0.5px` 次像素抗锯齿计算，导致边缘模糊发虚。

### 2. 形态绝对同构律（Zero-Exception Homogeneity）
* **整页风格必须纯粹**：全页 100% 统一为线性（Outline）或面性（Solid）；
* 平铺导航与列表严禁空心实心混用；极少数特殊业务状态（如局部选中态切换），留给人类做最终微调。

### 3. 色彩与视觉配重绑定（Token Binding & Optical Weight Balance）
* **杜绝物理硬编码**：禁止在 SVG 节点或 CSS 中手写十六进制色值（如 `#333`, `#666`）；
* **绑定系统文本色 Token**：图标色彩必须绑定系统的文本类颜色变量（如 `var(--text-primary)`, `var(--text-secondary)`, `var(--text-muted)`，或在父级继承 `currentColor`）；
* **解绑与邻近文本的强制同色（光学重量平衡）**：
  * **线性图标（Outline）**：墨水覆盖率低，可直接承接或继承主体文本色；
  * **面性/填充图标（Solid / Bold）**：墨水覆盖率高（60%~80%），**严禁死板绑定与正文完全相同的高对比色**。允许根据形态灵活选用次级或辅助文本色 Token（如 `--text-muted`）或调小尺寸，以减轻视觉锚点过重、墨块压迫感强的问题，实现图标与文本的光学平衡；
* **描边常数**：直接继承官方标准库预设（如 1.5px 或 2px），**严禁在单个图标节点内私自注入或篡改 `stroke-width`（调用即调用，禁止单体魔改）**。

### 4. 控件符号纯矢量律（Vectorized Functional Icons & Zero Hallucination）
* **控件符号杜绝字符伪造**：导航栏、操作按钮、表单中的功能符号严禁使用 Emoji 或文字符号替代；遇到需要重构的功能图标时，必须以内联 `<svg>` 形式装配，确保离线自包含且原生响应主题；
* **严禁滥杀内容媒体**：严禁将业务内容中的 `<img>` 标签（如头像、商品图片）误判为图标进行破坏或替换。

## 三、自由寻址与近似保底（Asset Resolution & Fallback）

### 1. 释放大模型语义匹配能力
* 不设僵化的词典限制。AI 凭借对英文概念的理解，自由在主流标准图标库（默认推荐 **Lucide Icons**，备选 **Remix Icon**、**Iconoir**）中寻找最贴切的官方英文全称（如 `search`, `compass`, `microscope`, `folder`, `settings`）。

### 2. 严禁手写 SVG Path（Zero Hallucination）
* 无论概念多冷门，**绝对禁止 AI 脑补手绘一段假想的 `<path d="...">`**。

### 3. 近似保底原则（拒绝空白占位符）
* 遇到高度特定领域的专业概念，若资产库无 100% 完全对应项：
  * **严禁挂载中性灰色占位框**（避免破坏页面的饱满度与节奏）；
  * 必须在目标库中选取**最邻近的近似语义图标**填补；
  * 在交付说明中轻量记录该处的近似推测，交由人类最终核准：
    > *“【图标待复核】：‘[业务名称]’因无完全对应项，当前暂用近似图标 `[icon-name]` 保障观感，待 UI 最终确认。”*

### 4. 存量工程资产白名单
* 若目标项目已有现成资产，调用 `scripts/extract_project_icons.js` 生成清单，只在已有的 Symbol 白名单中寻址，严禁私自引入外部新库。

---

## 四、原子补丁执行律（Atomic Patch Only）

* **严禁整页全量覆写**：严禁重新输出一整页 HTML 替换旧文件；
* **局部精确差分**：仅替换包含图标的目标节点标签，并在 CSS 中补齐尺寸与居中约束，绝不破坏周围已调优好的排版与事件逻辑。
