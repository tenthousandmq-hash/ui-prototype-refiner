# ui-typography-governance (排印与阅读人体工学治理)

面向专业设计师与工程流水线的纯代码/视觉排印工程基线。
排除了任何主观审美形容词，将文本排版彻底转化为**眼动工学物理常数与可静态走查的数学公式**。

---

## 一、 核心物理常数与量化指标

```
                  ┌───────────────────────────────┐
                  │ 黄金 Measure: 45~75字符 (30~45汉字) │
                  │ max-width: 65ch               │
                  └──────────────┬────────────────┘
                                 │
     ┌───────────────────────────┴───────────────────────────┐
     ▼                                                       ▼
【正文与长文本 (14~16px)】                               【标题体系 (20~36px+)】
line-height: 1.55 ~ 1.70                                line-height: 1.15 ~ 1.25
(舒展回行，留足眼动缓冲，杜绝墨块)                         (反向收紧，避免上下脱节散架)
```

### 1. 黄金行长测度（Measure）
* **行业依据**：Robert Bringhurst《The Elements of Typographic Style》
* **物理常数**：
  * **西文舒适带**：`45 ~ 75` 字符（最佳黄金中值 66 cpl）；
  * **中文舒适带**：`30 ~ 45` 汉字；
  * **容器硬红线**：文本阅读容器必须强制声明 `max-width: 65ch`（约 640px~760px），在大屏视口下严禁随父容器拉伸至 1000px+。

### 2. 逆向行高曲线（Inverse Leading Ratio）
* **物理常数**：字号越大，行高倍数必须反比例收紧，严禁全局通篇套用单一 `line-height`：
  * **正文阅读（14px ~ 16px）**：`line-height: 1.55 ~ 1.70`（绝对杜绝 $\le 1.3$ 的挤压墨块）；
  * **界面标签与表单（12px ~ 14px）**：`line-height: 1.35 ~ 1.45`（紧凑交互）；
  * **次级标题（18px ~ 20px）**：`line-height: 1.30 ~ 1.40`；
  * **主标题与展示字（24px ~ 36px+）**：`line-height: 1.15 ~ 1.25`（严禁大标题使用 1.5+，会导致行间脱节）。

### 3. 音阶式模块字阶（Modular Type Scale）
* **物理常数**：字号严禁随意手写奇数或孤岛数值（如 13px, 15px, 17px, 22px）。统一基于 $1.125$ (Major Second) 或 $1.20$ (Minor Third) 标尺收敛：
  * `12px`：辅助注释、时间戳、Badge 胶囊；
  * `14px`：标准正文、输入框、常规列表项；
  * `16px`：强调正文、Tab 标签、卡片标题；
  * `20px`：小模块标题 (Section Title)；
  * `24px`：页面二级主标题 (Page Subheading)；
  * `32px`：页面一级主标题 (Page Heading)。

### 4. 垂直节奏感与格式塔间距（Vertical Rhythm & Proximity）
* **物理常数**：
  * **段落节拍**：正文段落底部外边距必须基于字号相对单位：`margin-block-end: 0.85em`（严禁连打双 `<br>` 占位）；
  * **标题亲密性**：标题与下方正文的距离，必须显著小于标题与上方前文的距离：
    $$\text{Margin}_{\text{top}} \ge 1.5 \sim 2.0 \times \text{Margin}_{\text{bottom}}$$
    *(防止标题在视觉上飘向上一个段落)*。

## 二、 三阶段工作模式契约

本 Skill 在不同流水线阶段接受 `--mode` 参数以切换行为：

### 模式 1：`--mode=diagnostic`（事前排查 / 截图初评）
* **定位**：纯只读静态分析器（Linter / MRI）。**严禁修改任何代码。**
* **输入**：前端代码文件、CSS 样式表，或界面截图。
* **执行逻辑**：
  1. 扫描文本容器是否缺失宽度上限（Measure 检查）；
  2. 扫描正文字阶是否使用了过小行高（$\le 1.3$）；
  3. 扫描是否存在非标字号（如 13.5px、15px 等）；
  4. 扫描段落间距是否断裂。
* **输出**：结构化的《排印病灶清单》（按严重等级降序）：
  ```markdown
  ### [ui-typography-governance] 诊断报告
  - [致命] 中栏正文容器缺失 max-width，当前视口单行字数达 62 字（超标 40%），存在回行阅读障碍。
  - [致命] 正文类名 `.content-body` 行高为 1.25，字距过密形成墨块效应。
  - [硬伤] 标题 `.section-header` margin-top 与 margin-bottom 相等 (8px)，亲密性倒挂。
  - [警告] 发现 3 处使用了非标字号 13px，建议收敛至 12px 或 14px。
  ```

---

### 模式 2：`--mode=patch`（设计执行 / 规范化补丁）
* **定位**：原子级补丁生成器。**只针对排印规则做精准替换，不破坏任何业务逻辑与 DOM 结构。**
* **输入**：确认需要修复排印缺陷的目标文件。
* **执行逻辑**：
  1. 在全局 CSS 或容器根节点注入标准排印变量：
     ```css
     :root {
       --font-scale-xs: 12px;
       --font-scale-sm: 14px;
       --font-scale-base: 16px;
       --font-scale-lg: 20px;
       --font-scale-xl: 24px;
       --font-scale-2xl: 32px;
       --lh-tight: 1.2;
       --lh-normal: 1.4;
       --lh-relaxed: 1.65;
       --measure-optimal: 65ch;
     }
     ```
  2. 针对主阅读容器自动追加 `max-width: var(--measure-optimal)`，并执行居中或安全外补丁；
  3. 将密集正文的 `line-height` 统一挂载为 `var(--lh-relaxed)`；
  4. 注入 `margin-block-end: 0.85em` 保证自然呼吸感。
* **交付物**：Git 风格原子差异补丁（Diff）。

---

### 模式 3：`--mode=verification`（事后审核 / 终审门禁）
* **定位**：交付前客观硬红线闸门。
* **执行逻辑**：只检查是否存在绝对破坏体验的致命错误（Fatal Errors）：
  * [ ] 全屏长文本视口是否存在单行超过 75 字符（Measure 逃逸）；
  * [ ] 正文行高是否出现低于 1.4 的极端情况；
  * [ ] 是否存在未收拢的非标奇数字号；
* **主观裁决移交**：排版微调后的整体语感、行文优雅度与阅读顺畅感，**直接移交设计师肉眼终审**，机器不作主观评判。
